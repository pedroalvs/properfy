# Contracts — Inspector notices Web (045)

This feature **consumes** the F02-1 contract; it defines **no new endpoints** and does not
edit `packages/shared/openapi.json` or `api-types.ts`. The endpoints below are already on
`develop` (PR #1321) and typed into the generated client. This file is the consumer-side
reference the web code binds to.

## Consumed endpoints (AM/OP)

### `POST /v1/inspector-notices`
- **Auth**: AM/OP. **Header**: `Idempotency-Key: <uuid>` (required, stable across retries).
- **Body**: `PublishInspectorNoticeInput` = `{ title, body, critical, audience }`.
- **201**: `{ id, recipientCount, ... }` → snackbar "Notice published to {recipientCount} inspectors".
- **Errors** (envelope `{ error: { code, message, details? } }`):
  | Status | code | UI message |
  |---|---|---|
  | 422 | `INSPECTOR_NOTICE_NO_RECIPIENTS` | "No active inspectors match this audience." |
  | 400 | `INSPECTOR_NOTICE_INVALID_RECIPIENTS` (`details.inspectorIds`) | "Some selected inspectors are no longer active. Review the selection." + uncheck those ids |
  | 404 | `INSPECTOR_NOTICE_REGION_NOT_FOUND` | (region revalidated) "This region is inactive. Choose another region." |
  | 422 | `INSPECTOR_NOTICE_REGION_INACTIVE` | "This region is inactive. Choose another region." |
  | 400 | `IDEMPOTENCY_KEY_MISSING` | (never hit — the client always sends the header) |
  | 409 | `INSPECTOR_NOTICE_IDEMPOTENCY_PAYLOAD_MISMATCH` | generic retry message (not expected in normal flow) |
  | other | — | "Couldn't publish the notice. Try again." / offline: "You're offline. Check your connection and try again." |

### `GET /v1/inspector-notices`
- **Auth**: AM/OP. **Query**: `ListInspectorNoticesQuery` = pagination + `status` (`active`
  default / `archived` / `all`).
- **200**: `{ data: InspectorNoticeSummary[], pagination }`.

### `GET /v1/inspector-notices/{noticeId}`
- **Auth**: AM/OP. **Path**: `noticeId` via `params.path` (no `as any`).
- **200**: `InspectorNoticeDetail` (summary + `recipients[]`).
- **404**: `INSPECTOR_NOTICE_NOT_FOUND` → EmptyState "Notice not found" + "Back to notices".

### `POST /v1/inspector-notices/{noticeId}/archive`
- **Auth**: AM/OP. **Path**: `noticeId`.
- **200**: archived notice (idempotent — already-archived returns 200) → snackbar
  "Notice archived", refetch, InfoBanner "This notice is archived. Inspectors no longer see
  it."

## Supporting endpoints (option sources, read-only, existing)

- `GET /v1/inspectors?status=ACTIVE&pageSize=100` — multi-select options (all pages).
- `GET /v1/inspectors?status=ACTIVE&pageSize=1` — `pagination.total` for the ALL SMS ceiling.
- `GET /v1/service-regions?status=ACTIVE&pageSize=100` — region options with `inspectorCount`.

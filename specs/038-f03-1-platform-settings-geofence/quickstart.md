# Quickstart — F03-1

## Build & verify (inside the worktree)

```bash
pnpm --filter @properfy/shared build && pnpm --filter @properfy/shared test
pnpm --filter backend exec prisma generate
pnpm --filter backend typecheck && pnpm --filter backend lint && pnpm --filter backend test
pnpm --filter backend test:integration:db -- platform-settings inspection-geofence audit-log-coordinate-mask
pnpm --filter web typecheck && pnpm --filter pwa typecheck   # api-types regenerated
```

Regenerate the contract after route/schema changes and commit both files:

```bash
pnpm --filter backend generate:openapi
pnpm --filter @properfy/shared generate:types
```

Apply the migration locally (expand-only; timestamp regenerated by `prisma migrate dev`):

```bash
pnpm --filter backend prisma migrate dev --name platform_settings_and_execution_geo
```

## Try the API (operator token)

```bash
# Read all settings (defaults until a PUT happens)
curl -H "Authorization: Bearer $OP_TOKEN" localhost:3000/v1/platform-settings

# Turn the geofence radius down to 150 m, keep FLAG
curl -X PUT -H "Authorization: Bearer $OP_TOKEN" -H 'Content-Type: application/json' \
  -d '{"value":{"geofenceRadiusMeters":150,"geofenceMode":"FLAG","checkInWindowToleranceMinutes":15,"completionReminderEnabled":true,"completionReminderMinutesAfterWindowEnd":30}}' \
  localhost:3000/v1/platform-settings/fieldEvents

# A CL_ADMIN gets 403; an INSP gets 403; no token gets 401.
```

## Rollout

1. Apply migration (expand) → deploy backend. No data step (defaults live in code).
2. Deploy with `FLAG`. BLOCK stays dormant until the PWA sends accuracy (F03-3 in prod), X02 (permanent geocoding) in prod, and a property-geocoding audit.
3. To disable BLOCK without a deploy: `PUT /v1/platform-settings/fieldEvents` with `geofenceMode: 'FLAG'` (effective within 30 s).
4. Rollback: revert the backend deploy; new columns and `platform_settings` are harmless if left.
